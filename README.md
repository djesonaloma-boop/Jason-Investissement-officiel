
### ⚙️ Installation

#### Version 1 : Test sur téléphone (100% offline, file://)

1. Télécharge tous les fichiers dans un dossier
2. Ouvre `index.html` avec Chrome
3. Crée un compte → ton code `JAS-XXXXXX` est généré auto
4. Teste le lien : `index.html?ref=TONCODE`

> Pas besoin de serveur. `localStorage` gère tout.

#### Version 2 : Vrai serveur (parrainage entre téléphones)

```bash
npm install
node server.js
